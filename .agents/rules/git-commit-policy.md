# Git Commit Requirements
- BEFORE executing any `git commit` command, you MUST present the proposed commit message and a brief description of the changes to the user.
- DO NOT proceed with the commit until the user provides explicit approval (e.g., "Yes", "Proceed", or "LGTM").
- If the user provides a specific message or description, you MUST use that exact text for the commit instead of generating your own.
